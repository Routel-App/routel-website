**لوحة التحكم** هي الصفحة التي تفتح عليها كل جلسة: "لمحة عن الحجوزات والإيرادات وما يحتاج إلى متابعة اليوم". يمكن لأي دور مسجّل الدخول فتحها. وما تراه فيها يتبع صلاحياتك: فالبطاقة التي يعتمد مصدرها على وحدة لا يقرؤها دورك تُحذف ببساطة.

## يحتاج إلى اهتمامك

يظهر هذا القسم فقط عند وجود شيء يستدعي المتابعة. كل بطاقة تحمل عدداً وتنقلك مباشرة إلى القائمة المعنية:

| البطاقة | إلى أين تنقلك | متى تظهر |
| --- | --- | --- |
| فواتير متأخرة | الفواتير المتأخرة في **الفواتير** | فواتير صادرة تجاوزت تاريخ استحقاقها (حمراء) |
| فواتير قيد الانتظار | **الفواتير** | فواتير مسودة أو غير مدفوعة أو نهائية |
| تصنيفات مستحقة اليوم / متأخرة | **مركز التصنيف** | تصنيفات حان موعدها أو فات |
| مستندات بانتظار المراجعة | **المستندات** | مرفقات واردة لم يعتمدها أحد بعد |
| اقتراحات دفع للمراجعة | صندوق البريد المالي | اقتراحات دفع لم تُراجَع |
| طلبات تسجيل شركاء أعمال قيد الانتظار | **شركاء الأعمال** | تسجيلات عبر النموذج العام بانتظار اعتمادك |
| النسخة الاحتياطية لقاعدة البيانات مفقودة أو متأخرة | **الإدارة ← النسخ الاحتياطية** | لم تكتمل نسخة احتياطية في موعدها (حمراء) |
| إعداد واحد مطلوب: دولة هذا الفرع وعملته، قبل أول حجز | **الإدارة ← العملة والضريبة** | ما دامت الدولة على القيمة الافتراضية |
| مهام خلفية فاشلة أو متأخرة | **الإدارة ← سلامة النظام** | مهمة خلفية فشلت أو تأخرت (حمراء)؛ وقد تظهر بصيغة "تعذّر فحص سلامة النظام" |

## أحدث الحجوزات

أحدث ثمانية حجوزات حسب تاريخ الإنشاء، لكل منها رقم الحجز، والحالة، والعميل، والمسار POL → POD، وETD/ETA. ينقلك **عرض الكل** إلى قائمة [الحجوزات](/docs/bookings).

## مراحل الحجوزات

عدد الحجوزات في كل حالة، من الحجز قيد الانتظار حتى الشحنة مغلقة، مع شريط يوضح نصيب كل حالة من الإجمالي، على مدى كل الوقت.

## أرصدة العملاء

عند توفر بيانات، يظهر صف لكل شريك أعمال مرتّباً بالاسم، وفيه **المستحق** لكل عملة، أو **مسدد بالكامل** إذا لم يبقَ عليه شيء. ويعرض سطر **الإجمالي** مجموع الفواتير مضافاً إليها الإشعارات المدينة. ينقلك **عرض الكل** إلى [شركاء الأعمال](/docs/business-partners).
